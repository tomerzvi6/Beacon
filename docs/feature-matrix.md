## מה זרוע בדמו (מופעל ידנית — כרטיס רפואי ← "נתוני הדגמה")

התקנה חדשה מתחילה **נקייה**. טעינה/ניקוי בכפתור. הדמו כולל: יומן, משימות, תרופות+מינונים, התראת בי"ח (מחובר), 2 פוסטים+תגובות, מטפלת Maria (טגלוג) + דיווח בוקר + 2 הוראות, משפחה מדומה, סיכום AI סטטי (מחובר).

## פערים (מה אין)

1. חיבור אמיתי לבי"ח/קופה — מצב "מחובר" הוא סיפור בלבד
2. שרת מפורסם — **חבילת דיפלוי מוכנה** (backend/DEPLOY.md: Dockerfile+fly.toml, ~20 דק' עם חשבון Fly), נותרה הרצה + עדכון BACKEND_URL
3. תרגום LLM לטקסט חופשי של מטפל/ת
4. סנכרון בין מכשירים (תרופות/משימות/פיד/יומן/מטפלת)
5. ערוצי קליטה פסיביים: Share Extension / מייל ייעודי / וואטסאפ
6. התראות Push מרחוק (תזכורות מקומיות לתרופות — יש ✓)
7. Google Sign-In מושבת
8. סוכני backend (Guardian/Chief וכו') לא מחוברים לאפליקציה
9. TestFlight — דורש חשבון Apple Developer ($99) + העלאת build
